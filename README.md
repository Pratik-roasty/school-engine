- This is a simple API which help to search school data based on multiple parameters.
- Use following route to get all the data from the database: /SchoolEngine/schools
- For querying: /SchoolEngine/schools?Query1=abc&Query2=xyz&....
- Query parameters are listed below:
  1. SchoolName: any string
  2. Affiliation: String,
  3. Primary: "YES" || "NO",
  4. UpperPrimary: "YES" || "NO",
  5. Secondary: "YES" || "NO",
  6. HigherSecondary: "YES" || "NO",
  7. Hostelfacility: "YES" || "NO",
  8. Transport:"YES" || "NO",
  9. Playground: "YES" || "NO",
  10. DigitalEd: "YES" || "NO"
